# 配置接线小结 · spec 014–018

> 2026-11-04 · 覆盖 `specs/014` – `specs/018` · 前置：`docs/design-audit.md`

## 一句话结论

一个「配了但没生效」的审计发现，滚成了 **5 个 spec / 7 个 commit / 42 条新测试**，
把零引用从 **22 降到 16**，并且**顺带修了两个真 bug**、建立了三层防止复发的机制。

过程中**三次被我自己的测试拦住** —— 这是本轮最值得记的事。

## 起点

设计审计（`docs/design-audit.md`）扫出 22 个问题：21 个零引用 + 1 个只在注释里。
其中 4 个是「声明的值和实际行为不一致」：

| 字段 | 声明 | 实际 |
|---|---|---|
| `RERANK_CANDIDATES` | 50 | rerank 拿到全部候选 |
| `GRAPH_TIMEOUT_MS` | 200 | 代码里另一个常量 `0.2` |
| `AGENT_KEY_HEADER` | `X-Agent-Key` | 实现是 `Authorization: Bearer` |
| `TIME_CONF_MIN` | 0.5 | 只在注释里被提到 |

这四类比「压根没这个配置」危险 —— **你以为调了，其实没调**。

## 三次被自己的测试拦住

这是本轮最有价值的部分 —— 不是「我发现了问题」，是「**机制发现了我不该忘的事**」。

### ① 015：白名单防腐测试抓 `TIME_CONF_MIN`

`test_whitelist_entries_are_still_unused` 挂了：

```
FAILED test_config_usage.py::test_whitelist_entries_are_still_unused
```

因为 `TIME_CONF_MIN` 接上后有消费点了，但它还在白名单里。

**白名单必须随接线进度收缩**，否则会腐烂成「历史上曾经没用过的字段集合」。

### ② 017：同一个测试抓 `VECTOR_TIMEOUT_MS`

同样的失败，同样的原因。spec 017 的 D7 甚至**预先写好了这条预期**。

### ③ 018：015 埋的钩子抓分级

`test_real_resolver_confidence_is_binary` 挂了，报错信息是 015 里手写的：

```
置信度出现中间值 {0.6, 1.0, 0.0} —— 015 的 Notes 需要更新
```

这条测试的作用不是保护行为，是**提醒下游契约变了**。

> 如果这三次都靠人眼，我会漏掉至少两次 —— 因为第三次是我改完之后才想起来的。

## 建立了什么机制

三层，从粗到细：

| 层 | 文件 | 抓什么 |
|---|---|---|
| **字段级** | `test_config_usage.py`（9 条） | 有定义但无消费点 |
| **行为级** | `test_config_wiring.py`（11 条） | 改了配置值但行为没变 |
| **契约钩子** | `test_real_resolver_confidence_is_tiered` 等 | 下游假设变了 |

字段级检测里有两个**元测试**：

- `test_detector_actually_detects` —— 造一个必然无人用的字段，确认检测器会报
- `test_comments_do_not_count_as_consumers` —— 注释提到不算用了

> 没有元测试的检测器，写错了也是全绿 —— 那才是最大的假实现。

## 技术教训（可直接复用）

1. **`timeout=None` 在 httpx 里是「禁用超时」，不是「沿用 client」**
   —— 必须「不传 kwarg」才能沿用。这个 bug 是「不传时不受影响」的反向断言抓到的；
   只写「传了就生效」的测试会完全漏过去。

2. **分级不该改变默认行为**
   —— 选 0.6 而不是 0.4，让推算档刚好过 `TIME_CONF_MIN=0.5`。
   「改变召回宽窄」是产品决策，不该藏在技术动作里。

3. **判据要说清楚是「哪一个维度」**
   —— 置信度分档的判据不是「是否依赖 today」（那样 `昨天` 会被误伤），
   而是「窗口宽度从哪来」。

4. **修漂移的过程本身会造出新漂移**
   —— 014 里第一版加了 `GRAPH_TIMEOUT_FALLBACK_S = None` 兜底，写完立刻删掉。

5. **默认值也是一种文档**
   —— `AGENT_KEY_HEADER = "X-Agent-Key"` 让两个读者（人和 AI）都以为存在这个协议。

6. **改 trace 字段要先数构造点**
   —— `recall.py` 有 4 处返回 `RecallResult`，只改一处导致 6 个测试挂 `KeyError`。
